# TerraLog

Sistema para gerenciamento de sondagens geotécnicas.

## Objetivos

- Cadastro de obras
- Cadastro de furos
- Registro SPT
- Registro de camadas
- LT
- Croqui
- Geração automática de PDF

## Tecnologias

Backend
- Java 21
- Spring Boot
- PostgreSQL

Mobile
- Flutter

Infra
- Docker
